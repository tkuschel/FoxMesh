# Create New Project

## PlatformIO

1. Open VSCodium.

2. Click on the **Alien Head** (ant head) icon of the PlatformIO in the left Activity bar.
Continue clicking on "Create New Project", PlatformIO Core -- **PIO Home** opens.

3. Again, press the button **+ New Project** and fill in the *Name* of the new project, e.g. `FoxMesh`.

4. Select the board `TTGO LoRa32-OLED v2.1.6`

5. Choose the Framework either `Arduino` or `Espidf`, we select `Espidf` i.e. **ESP-IDF**.

6. We do not use the default location but `$HOME/github/FoxMesh`.
